🚗 Car Game (Python)

A lightweight Python-based car racing game built using Pygame, designed to provide a fast, smooth, and interactive driving experience. The game focuses on lane switching, obstacle avoidance, dynamic scoring, and responsive controls.

🎮 Features

Smooth car movement with keyboard controls
Dynamic obstacle generation with increasing difficulty
Real-time score tracking
Collision detection for game-over events
Lightweight Pygame architecture with modular code structure

🛠 Tech Stack

Python 3.x
Pygame

▶️ How to Run

pip install pygame
python main.py
