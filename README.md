Parking System

A Python + SQL based parking system where users log in, check available slots, enter vehicle details, and receive a token for the guard.

**Features**
Login Authentication
Vehicle Type Selection
Slot Availability Check
User Detail Entry
Auto-Generated Parking Token

**Flow**
1. User logs in
2. Selects vehicle type
3. System checks free slots
4. User enters details
5. System generates a parking token for guard verification



Python (frontend logic)

SQL (backend database)
