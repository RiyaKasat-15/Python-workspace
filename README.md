# Python-workspace
Python Image Processing Projects

This folder contains a collection of Python-based image processing programs demonstrating fundamental operations such as image I/O, color space manipulation, channel extraction, and basic drawing techniques.

Projects Included

1. Reading, Writing, and Displaying Images
Basic image I/O operations using Python to load, save, and visualize images.

2. Grayscale Conversion
Converts color images into grayscale using intensity transformation methods.

3. HSV Color Space & Hue Extraction
Transforms images into the HSV color space and isolates the hue component for analysis.

4. RGB to Grayscale Conversion
Converts RGB images to grayscale using weighted channel formulas.

5. Color Channel Extraction (R, G, B)
Separates and displays the individual Red, Green, and Blue channels of an image.

6. Drawing on Images
Uses Python imaging functions to draw shapes, lines, and text directly on images.
